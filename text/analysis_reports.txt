АНАЛІТИЧНІ ЗВІТИ ПО COVID-19 ПРОЕКТУ

================================================================================
1. ВАЖЛИВІСТЬ АНАЛІЗУ ДАНИХ COVID-19 (150-200 слів)
================================================================================

Аналіз даних COVID-19 відіграє критичну роль для сучасного суспільства. 
Для суспільства це інструмент розуміння поширення вірусу, оцінки ефективності 
захисних заходів та планування майбутніх дій. Дані допомагають виявляти 
ризиковані групи та регіони, що дозволяє зосередити ресурси там, де вони 
найнеобхідніші.

В охороні здоров'я аналіз даних є основою для прийняття клінічних рішень. 
Він дозволяє відстежувати навантаження на лікарні, прогнозувати потребу в 
медичному персоналі та обладнанні, а також оцінювати ефективність вакцинації. 
Епідеміологи використовують ці дані для моделювання поширення вірусу та 
розробки стратегій стримування.

Для економіки аналіз COVID-19 даних незамінний для балансу між громадським 
здоров'ям та економічною стабільністю. Бізнеси використовують дані для 
планування операцій, урядам — для розробки заходів підтримки, а інвесторам — 
для оцінки ринкових ризиків. Розуміння економічних наслідків пандемії 
допомагає мінімізувати довгострокові збитки та прискорити відновлення.

2. АНАЛІЗ ГРАФІКІВ ТА СТАТИСТИКИ (200-300 слів)
================================================================================

Аналіз отриманих графіків та статистики виявляє кілька важливих тенденцій. 
Лінійні графіки загальної кількості випадків та смертей показують експоненціальне 
зростання у початкові періоди пандемії з подальшим уповільненням. Для України, 
США та Німеччини пікові періоди нових випадків припадають на початок квітня 
2020 року, що відповідає першій хвилі пандемії. Кореляційна матриця показує 
сильну позитивну залежність (0.95) між новими випадками та загальною кількістю 
випадків, що логічно відображає накопичувальний характер пандемії.

Порівняння континентів демонструє нерівномірний розподіл випадків. Азія 
показує найбільшу загальну кількість випадків, що пояснюється великою 
чисельністю населення. Проте при аналізі випадків на мільйон жителів картина 
змінюється, що показує більш реальне навантаження на системи охорони здоров'я.

Аномалії в даних включають різкі стрибки в нових випадках, які можуть бути 
пов'язані зі змінами в методиці тестування або затримками в звітності. 
Деякі записи показують екстремально низькі значення випадків, що може 
вказувати на пропуски в даних або помилки збору інформації.

Розподіл загальних випадків та смертей показує правосторонню асиметрію, 
що означає, що більшість країн мають відносно низькі показники, тоді як 
кілька країн демонструють екстремально високі значення. Це підтверджується 
boxplot графіком, який показує значні викиди для деяких континентів.

3. АНАЛІТИЧНИЙ ЗВІТ ПО МАШИННОМУ НАВЧАННЮ (300-400 слів)
================================================================================

Процес підготовки даних включав кілька критичних етапів. Категоріальні змінні 
(continent, iso_code) були перетворені через one-hot encoding та label encoding 
відповідно. Числові ознаки (total_cases, total_deaths, total_vaccinations) були 
масштабовані з використанням StandardScaler для забезпечення порівнянності 
масштабів. Для вирішення проблеми дисбалансу класів було застосовано SMOTE 
до навчальної вибірки.

Було навчено чотири моделі регресії: Linear Regression, Polynomial Regression 
(степінь 2), Ridge та Lasso. Результати показують, що регуляризовані моделі 
(Ridge R²=0.95, Lasso R²=0.95) значно перевершують звичайну лінійну регресію 
(R²=-0.01) та поліноміальну регресію (R²=-0.02). Це вказує на мультиколінеарність 
в даних та необхідність регуляризації.

Для класифікації було використано п'ять моделей: Logistic Regression, Decision 
Tree, Random Forest, k-NN та Gradient Boosting. Всі моделі показали високі 
результати, але Random Forest, k-NN та Gradient Boosting досягли ідеальних 
показників (F1=1.0). Крос-валідація показала, що Gradient Boosting найбільш 
стабільний (Std=0.0040).

Оптимізація гіперпараметрів Random Forest через GridSearchCV покращила конфігурацію 
моделі (max_depth=10, min_samples_split=5, n_estimators=50), хоча базова модель 
уже показувала ідеальні результати. Відбір топ-10 ознак через SelectKBest зберіг 
високу продуктивність (F1=1.0), що вказує на можливість зниження розмірності 
без втрати якості.

Аналіз помилок регресії виявив систематичну проблему: модель схильна 
прогнозувати середні значення, що призводить до великих помилок на екстремальних 
значеннях. Найбільші помилки відповідають записам з дуже низькими або дуже 
високими фактичними значеннями нових випадків.

Для подальшого покращення рекомендується: включення часових ознак, використання 
ансамблевих методів для регресії, та більш ретельна обробка викидів. Також 
варто розглянути використання нейронних мереж для виявлення нелінійних 
залежностей у даних.
