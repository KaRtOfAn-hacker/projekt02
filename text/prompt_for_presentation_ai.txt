СТРУКТУРА ПРЕЗЕНТАЦІЇ (14 слайдів):

СЛАЙД 1: ТИТУЛЬНИЙ
- Назва проєкту: "Аналіз та прогнозування даних COVID-19"
- Підзаголовок: "Проект з аналізу даних та машинного навчання"
- Імена учасників команди
- Дата презентації
- Репозиторій: github.com/KaRtOfAn-hacker/projekt02

СЛАЙД 2: ВСТУП
- Яку проблему вирішували?
- Чому аналіз даних COVID-19 важливий для суспільства, охорони здоров'я, економіки?
- Яку кінцеву мету поставили?
- Приклад тексту: "Пандемія COVID-19 створила безпрецедентний обсяг даних. Наша мета — використати методи машинного навчання для прогнозування динаміки захворюваності та виявлення факторів, що впливають на поширення вірусу."

СЛАЙД 3: ДЖЕРЕЛА ДАНИХ
- Джерело: Our World in Data (OWID)
- Характеристики датасету:
  * Кількість рядків та стовпців (200,000+ рядків, ~60 стовпців)
  * Часовий діапазон (2020–2023 роки)
  * Географічне покриття (понад 200 країн та регіонів)
- Ключові змінні (3-5 найважливіших):
  * new_cases — щоденний приріст нових випадків
  * new_deaths — кількість нових летальних випадків
  * total_vaccinations — загальна кількість вакцинованих
  * population — населення країни
  * gdp_per_capita — ВВП на душу населення

СЛАЙД 4: ПІДГОТОВКА ДАНИХ
- Обробка пропущених значень (скільки було, як обробили)
- Видалення дублікатів
- Масштабування числових змінних (StandardScaler)
- Кодування категоріальних змінних (One-Hot, Label Encoding)
- Створення нових ознак (growth_rate, high_cases)
- Покажіть "до і після" — як виглядали дані до очищення і після

СЛАЙД 5: ВИБІР ЦІЛЬОВОЇ ЗМІННОЇ
- Для регресії: new_cases — чому саме ця змінна?
- Для класифікації: high_cases — як визначили поріг?
- Логіка вибору: що хотіли прогнозувати і навіщо?

СЛАЙД 6: МЕТРИКИ ОЦІНКИ
Для класифікації:
- Accuracy — Загальна точність
- Precision — Точність позитивних прогнозів
- Recall — Повнота виявлення
- F1-Score — Баланс Precision та Recall

Для регресії:
- MSE — Середня квадратична помилка
- MAE — Середня абсолютна помилка
- R² — Частка поясненої варіації

Поясніть: Чому обрали саме ці метрики для вашої задачі?

СЛАЙД 7: МОДЕЛІ МАШИННОГО НАВЧАННЯ
Класифікація:
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting

Регресія:
- Linear Regression
- Ridge
- Lasso
- Polynomial Regression

Поясніть: Чому саме ці моделі? Які їх особливості?

СЛАЙД 9: ВІЗУАЛІЗАЦІЯ РЕЗУЛЬТАТІВ
- Матриця плутанини для найкращої класифікаційної моделі

- Розподіл помилок (гістограма residuals)
- Порада: Кожен графік має бути підписаний та пояснений!

СЛАЙД 10: ГІПЕРПАРАМЕТРИЧНА ОПТИМІЗАЦІЯ
- Яку модель оптимізували? (Random Forest)
- Які параметри перебирали? (n_estimators, max_depth)
- Метод: GridSearchCV
- Результат: найкращі параметри
- Вплив: як змінились метрики до/після оптимізації?
- Приклад: "Після GridSearchCV з параметрами n_estimators=[50,100,200] та max_depth=[5,10,20], найкращі: n_estimators=200, max_depth=10. F1-Score покращився з 0.84 до 0.87."

СЛАЙД 11: АНСАМБЛЕВІ МЕТОДИ

СЛАЙД 12: ПРОГНОЗУВАННЯ

СЛАЙД 13: ВИСНОВКИ
- Основні досягнення проєкту
- Найкраща модель для класифікації та регресії
- Як моделі можуть бути використані на практиці?
- Труднощі та обмеження
- Приклад: "Gradient Boosting показав найкращі результати для класифікації (F1=0.82). Модель може бути корисною для раннього попередження про спалахи. Обмеження: модель не враховує нові штами вірусу та зміни в політиці тестування."

ДОДАТКОВА ІНФОРМАЦІЯ ДЛЯ ВИКОРИСТАННЯ В ПРЕЗЕНТАЦІЇ:

Технологічний стек:
- Python 3.x
- Pandas — обробка даних
- Scikit-learn — машинне навчання
- Matplotlib/Seaborn — візуалізація
- Imbalanced-learn — SMOTE для балансування класів

Ключові результати:
- Найкраща класифікація: Gradient Boosting (F1 ≈ 0.82)
- Найкраща регресія: Ridge Regression (R² ≈ 0.76)
- Топ ознаки: total_cases, population, gdp_per_capita

Основні виклики та рішення:
- Незбалансовані класи → SMOTE
- Пропущені значення → медіана та 0
- Різні масштаби ознак → StandardScaler
- Перенавчання → регуляризація та cross-validation
